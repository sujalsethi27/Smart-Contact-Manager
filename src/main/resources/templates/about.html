About Smart Contact Manager

A simple and secure contact management system

📘 About the Project

Smart Contact Manager is a web application that helps users store and manage their contacts securely. It allows users to add, update, search, and delete contacts from a single platform.

This project is developed as a learning-based application using modern backend technologies and follows a clean MVC architecture.

✨ Key Features

🔐 Secure Authentication

User authentication and authorization are implemented using Spring Security to protect user data.

📇 Contact Management

Easily add, edit, search, and delete contacts with a clean and user-friendly interface.

🛠️ Technologies Used

• Spring Boot
• Spring MVC
• Spring Security
• Thymeleaf
• Hibernate / JPA
• MySQL
• HTML & CSS
